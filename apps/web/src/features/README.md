# Frontend Feature Modules (`src/features/`)

Each domain feature in Vaultz owns its feature-specific UI components, TanStack Query hooks, API functions, Zod form schemas, and TypeScript contracts:

- `accounts/` — Financial accounts management (Milestone 3)
- `transactions/` — Income, expenses, and account-to-account transfers (Milestone 4)
- `categories/` — Income and expense categories (Milestone 5)
- `budgets/` — Periodic category budgets (Milestone 6)
- `savings/` — Savings goals and progress tracking (Milestone 8)
- `reports/` — Cash-flow analytics and financial exports (Milestone 10)

> **v0.1 Initialization Rule:** Per `AGENTS.md`, unrequested financial features are not pre-implemented during Milestone 1. Feature directories are populated as each vertical slice milestone is developed.
